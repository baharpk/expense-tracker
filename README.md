# Expense Tracker

A simple command-line expense tracking application built with Python and Pandas.

## Features

- Add new expenses
- Store data in a CSV file
- View the most recent expense
- Display all expenses grouped by category
- Calculate total expenses
- Simple command-line interface (CLI)

## Technologies Used

- Python
- Pandas
- CSV
- Datetime

## Sample Menu

1. Add Expense
2. View Latest Expense
3. View All Expenses
4. Exit

## Skills Demonstrated

- File handling
- CSV data processing
- Data analysis with Pandas
- Functions
- Loops
- Conditional statements
- User input validation
- Command-line application development
