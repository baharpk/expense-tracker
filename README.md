# Expense Tracker

A simple command-line expense tracking application built with Python and Pandas.

## Features

- Add new expenses
- Store data in a CSV file
- View the most recent expense
- Display all expenses grouped by category
- Calculate total expenses
- Simple command-line interface (CLI)

## Technologies Used

- Python
- Pandas
- CSV
- Datetime

## How to Run

1. Clone the repository

bash
git clone https://github.com/YOUR_USERNAME/expense-tracker-python.git
2. Install Pandas

bash
pip install pandas
3. Run the program

bash
python working.py

## Sample Menu

1. Add Expense
2. View Latest Expense
3. View All Expenses
4. Exit
